# SeaArt NGワードチェッカー辞書 v2.0.0

2026-11-16 作成。既存のNSFW候補辞書を拡張し、日本語・英語・中国語の政治、中国関連、侮辱・暴言、差別・属性関連、宗教、暴力・犯罪・賭博、薬物・嗜好品、自傷関連の候補を統合。

これは「NG原因になりそうな文字列を広く探す」辞書であり、SeaArtの禁止語を確定した一覧ではありません。文脈判定、単語境界判定、複数語のAND判定はしません。短語・一般語もそのまま検出します。属性名や信仰名の収録は、その人々や言葉への価値判断を意味しません。

## 使用ファイル
- seaart_ng_dictionary_web.json：Web読み込み用。既存v1と同じ entries / t,n,l,c,r を維持。
- seaart_ng_dictionary_v2.json：出典、カテゴリ、ユーザー報告などを保持する詳細辞書。
- seaart_ng_dictionary_v2.csv：UTF-8 BOM付き。編集用。
- seaart_ng_dictionary_stats.json：実際の収録件数・分類集計。
- covered_terms.csv：長語の削除記録と、その語を拾う短語との対応。
- validation.json：検証結果。
- ATTRIBUTION.md / licenses：出典・ライセンス。

## 照合方法
入力と辞書を NFKC → Unicode casefold の順に正規化し、単純な部分文字列一致で照合してください。JavaScriptで従来どおり lowerCase を使う場合、Unicode casefold と完全に同じではありません。厳密な再現には casefold 対応処理が必要です。

例：自由研究 → 自由、トリミング → リミング、ピエロ → エロ。エロ漫画・エロ動画・エロアプリはいずれもエロで検出します。ひらがな／カタカナ、簡体字／繁体字、語中空白の有無は別表記として扱い、自動変換はしません。正規表現ではなく文字列として照合します。

## 整理方法
表記が同じ正規化語は統合しました。さらに、既に登録された短語を含む長語を削除しました。たとえばエロ漫画はエロで検出できるため別登録しません。日本語・英語など言語をまたいで同じ文字列が含まれる場合も同様です。

この整理で「何かの候補に一致するか」という検出範囲は減りませんが、ハイライトされる文字列は短くなり、長語のカテゴリは結果に出ない場合があります。カテゴリ・出典は残った語自体のものを優先し、長語の情報は covered_terms.csv に記録しています。カテゴリ別件数は主カテゴリで1語1件の集計です。

v1内の正規化重複も統合したため、v1の2363行と比較すると単純な足し算にはなりません。新規候補数と削除件数は集計JSONを参照してください。

## 収集方針
1. 既存v1全件を入力として保持。
2. 公開罵倒語集LDNOOBWの日英中リスト、SpaceGatherのvulgarリストを追加。原資料が混合カテゴリのものは無理に性的・侮辱などと断定せず混合カテゴリに格納。
3. 政治・歴史・社会・宗教・薬物・暴力等は一般に実在する名称・用語を編集追加。日本語、簡体字・繁体字、英語の主な表記を追加。全ての名称の個別辞典照合やSeaArtでの検証は行っていません。
4. Citizen Lab等の検閲研究は分類方針の参考にしましたが、その大規模データセットは取り込んでいません。dablelv/dirty-cnwordsもライセンスを確認できなかったため一括転載していません。
5. 「自由」は会話でのユーザー報告を反映。その他は原則候補扱い。
6. 元辞書と全追加候補について、整理後も少なくとも1語が一致すること、重複・冗長な包含語が残っていないこと、CSV・JSON件数の一致を検証。

短語、一般語、多義語も意図的に採用しています。false_positive_riskは参考メタデータであり、除外・抑制には使用しません。v1由来の参考分類を引き継ぎ、新規分は文字数の簡易目安を使用しています。
